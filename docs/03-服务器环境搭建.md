# 3. 服务器环境搭建

## 准备服务器登录凭证

阿里云控制台用「手机号 + 验证码」登录的是**账号**，SSH 登录服务器需要单独的凭证。二选一：

### 方式 A：重置 root 密码（最简单）

1. 阿里云控制台 → **ECS** / **轻量应用服务器** → 找到你的实例
2. 点击实例 → **重置密码**（或**重置实例密码**）
3. 设置强密码并记录
4. **重启实例**后生效

### 方式 B：SSH 密钥对（更安全）

1. 阿里云控制台 → **密钥对** → **创建密钥对** → 下载 `.pem` 文件（**只能下载一次，妥善保存**）
2. 回到**密钥对**页面 → 点右侧 **绑定密钥对** → 选择你的实例
3. **重启实例**后生效

> **注意：** 绑定密钥对后阿里云默认会禁用 root 密码登录。如果需要保留密码登录（方便 Navicat SSH 通道填密码），登录服务器后改 `/etc/ssh/sshd_config`，把 `PasswordAuthentication yes` 和 `PermitRootLogin yes` 打开，再执行 `systemctl restart sshd`。

## 连接服务器（MobaXterm）

1. 打开 MobaXterm → 左上角 **Session** → 选 **SSH**
2. 填写：
   - **Remote host**：阿里云服务器公网 IP
   - **Specify username**：勾选，填 `root`
   - **Port**：`22`
3. 如果用方式 B（密钥登录）：点 **Advanced SSH settings** → 勾选 **Use private key** → 选择 `.pem` 文件
4. 点 **OK** 连接，首次会提示确认指纹，输入 `yes`
5. 方式 A 输入 root 密码即可登录；方式 B 无通信短语则直接进入

## 更新系统

```bash
apt update && apt upgrade -y
```

- `apt update`：更新软件包列表
- `apt upgrade -y`：升级已安装的软件包，`-y` 自动确认

## 安装 Java 21

```bash
apt install openjdk-21-jdk -y
java -version
```

验证输出应包含 `openjdk version "21.x.x"`。

> **为什么是 Java 21**：项目 `pom.xml` 中 `<java.version>21</java.version>`，服务器和本地的 Java 版本必须匹配。

## 安装 MySQL 8.0

```bash
apt install mysql-server -y
systemctl start mysql
systemctl enable mysql
```

- `systemctl start`：立即启动服务
- `systemctl enable`：设置开机自启

验证：

```bash
systemctl status mysql
```

看到 `active (running)` 就表示正常。

## 安装 Nginx

```bash
apt install nginx -y
systemctl start nginx
systemctl enable nginx
```

验证：在浏览器访问 `http://你的服务器IP`，看到 "Welcome to nginx!" 页面说明安装成功。

## 关于 systemctl 的常用命令

| 命令 | 作用 |
|------|------|
| `systemctl start 服务名` | 启动服务 |
| `systemctl stop 服务名` | 停止服务 |
| `systemctl restart 服务名` | 重启服务 |
| `systemctl status 服务名` | 查看服务状态 |
| `systemctl enable 服务名` | 设置开机自启 |
| `systemctl disable 服务名` | 取消开机自启 |
| `journalctl -u 服务名 -f` | 实时查看服务日志 |
